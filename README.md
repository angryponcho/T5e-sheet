# T5e Character Sheet

A Roll20 character sheet for T5e, Trevor's homebrew D&D 5e rules.

## Layout

- `sheet/trevors.html`: the sheet's HTML and sheet worker script
- `sheet/trevors.css`: the sheet's styles
- `art/`: images the CSS uses

## Using it in Roll20

You need a Pro subscription as the GM.

1. Game Settings, then Character Sheet Template: **Custom**.
2. Leave **Legacy Sanitization unchecked**.
3. Paste `sheet/trevors.html` into the HTML tab and `sheet/trevors.css` into the CSS tab, then save.

For development, use the Custom Sheet Sandbox (app.roll20.net/sheetsandbox).
