# Art assets

Images used by the sheet's CSS. Reference them by their raw GitHub URL:

    https://raw.githubusercontent.com/<owner>/<repo>/main/art/<file>

Keep file names lowercase with no spaces. Roll20 sends every image through its image proxy, so updates can take a little while to show.

## Sources

- The `.svg` frames and `insperation.gif` come from [mperes/Images-for-Roll20-5E-images](https://github.com/mperes/Images-for-Roll20-5E-images). That repo has no license. They're used here only for a private home game, and are meant to be replaced with original art eventually.
- The coin, death-save and inspiration-box PNGs and the paper texture were originally hosted on imgur.
